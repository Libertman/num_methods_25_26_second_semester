# Приближение табличных функций сплайнами и МНК

Варианты методов для сплайнов:

1. квадратичный сплайн, узлы интерполяции совпадают с узлами сплайна (одна сетка)
2. квадратичный сплайн, узлы интерполяции не совпадают с узлами сплайна (две сетки)
3. квадратичный сплайн, узлы интерполяции совпадают с узлами сплайна (одна сетка) с пропадающими узлами
4. кубический сплайн с граничными условиями на первую производную
5. кубический сплайн с граничными условиями на вторую производную
6. кубический сплайн с пропадающими узлами
7. Эрмитов сплайн, вычисление производных в узлах производить по усреднению секущих (внутренние узлы) и по интерполяции по Лагранжу по трем точкам (граничные узлы).

Варианты для МНК:

8. Базисная система полиномов $x^i$
9. Базисная система полиномов Чебышева

Численные исследования проводятся для обеих функций и равномерной сетки, число узлов $n>100$.

Для исследований и построения графиков функции вычисляются на проверочной сетке - в большом количестве точек, например 10000, которые не совпадают с узлами сетки для построения полинома или сплайна.

Провести сравнение полученных результатов в первой и второй работах, т.е. для интерполяционных полиномов, сплайнов и МНК.

Система уравнений для вычисления коэффициентов должны решаться методом, соответствующим виду системы и реализованным самостоятельно, без использования готовых библиотечных методов. Для положительно-определнной системы должен использовтаься метод Холецкого, для трехдиагоналной - метод прогонки. Для некоторых вариантов можно обойтись без решения системы, тогда в работе должен использоваться именно такой алгоритм.

В программе должен быть отдельная функция для задачи вычисления коэффициентов интерполянта, а другая функция -- для получения интерполяции в новых точках.

### Исследования на 7 баллов

Сплайны:

1. Для малого числа узлов (3..10) вычислить в ручную на бумаге значения сплайна по заданию и фактической ошибки (разность между значением функции и интерполянта) в узлах и серединах между узлами. Получить сплайн в каноническом виде (по степеням х).
2. Иллюстрация работы метода. Требуется построить на одном графике функцию, сплайны для 3 вариантов небольшого числа узлов (5...10), отметить узлы. На другом графике построить функции поточечной ошибки для этих же сплайнов.
3. Зависимость ошибки интерполяции от количества узлов (кусочных функций). Требуется построить график максимальной ошибки на отрезке в зависимости от числа узлов: 5...100. Для каждого случая вычисляется ошибка - норма разности вектора значений функции и сплайна на проверочной сетке.
4. Если используется производная на краях отрезка, построить график зависимости максимальной ошибки от значения производной на краях отрезка, в интервал изменения производной включить точное значение и точку 0. Если это значение не используется, например, при условии пропадающего узла, построить график зависимости максимальной ошибки от отклонения координаты пропадающего узла от настоящей, координату менять с небольшим шагом в сторону ближайшего конца отрезка, не доходя до него.

МНК:

5. Ручной расчет тестового примера сделать для полинома 2 порядка и 5 узлов. Вычислить максимальную ошибку –- разность между значением функции и полинома в узлах и серединах между узлами.
6. Иллюстрация работы метода. Построить полиномы 1, 2 и 3 порядков по методу наименьших квадратов для выбранного числа узлов, 100..200. Построить график функции и полиномов, отметить узлы. Вычислить ошибку в узлах и в серединах между узлами. Построить график ошибки для этих полиномов.
7. Исследование зависимости максимальной ошибки от числа узлов для полинома 3 степени, число узлов 10..1000.
8. Исследование зависимости максимальной ошибки от степени полинома, 2..10, для выбранного числа узлов, 100..200.

### Исследования на 8-10 баллов

Сплайны, один из пунктов:

9. Зависимость ошибки интерполяции при возмущении данных. В значение функции в точках сетки для построения полинома вносятся возмущения максимальной величины 1%, 2%, 3%, 4%, 5%. Возмущения вносятся в каждую точку случайно. Требуется вычислить относительную ошибку по всему отрезку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.
10. Модифицировать сетку так, чтобы для некоторого числа узлов ошибка стала меньше, чем на исходной сетке. Привести формулу для узлов сетки. Выполнить пп.2-3 для этих условий.
11. На основе данной функции построить функцию, имеющую разрыв первой производной вблизи середины отрезка, точка разрыва производной не должна попадать в узел сетки. Выполнить пп.2-3 для этих условий.

МНК, один из пунктов:

12. Зависимость ошибки апроксимации при возмущении данных. В значение функции в точках сетки для построения полинома вносятся возмущения максимальной величины 1%, 2%, 3%, 4%, 5%. Возмущения вносятся в каждую точку случайно. Требуется вычислить относительную ошибку по всему отрезку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.
13. Исследование влияния весов. Ввести вес для каждой точки данных, сумма весов равна 1. Построить график функции и полиномов 1, 2 и 3 порядков для разного значения веса у одной выбранной точки. Построить график зависимости ошибки в этой точке и максимальной ошибки при изменении веса, для полинома 2 порядка.
14. На основе данной функции построить функцию, имеющую разрыв первой производной вблизи середины отрезка, точка разрыва производной не должна попадать в узел сетки. Выполнить пп.2-3 для этих условий.
