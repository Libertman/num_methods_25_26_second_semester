# Задания к курсу "Численные методы", уровень 2

## Темы работ

1. Полиномиальная интерполяция таблично-заданных функций (1 лабораторная).
2. Полиномиальная аппроксимация данных сплайнами и методом наименьших квадратов (лабораторная 2).
3. Численное интегрирование методами Ньютона-Котса (3).
4. Численное интегрирование методами типа Гаусса (4).
5. Численное решение задачи Коши методами типа Рунге-Кутты (5).
6. Численное решение задачи Коши методами типа Адамса (6).
7. Численное решение краевой задачи (7).
8. Только для ПМ: курсовая работа по сравнению методов для одной из тем.

## Задания

[results](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/results.md) - список студентов, номер варианта, итоговая таблица результатов.

[variants](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/variants.md) - варианты индивидуальных заданий для каждой лабораторной.

По фамилии в файле results находим свой номер, по номеру в файле variants находим задание.

В файлах по каждой лабораторной (лаб1_ и т.п.) даны названия методов и описания исследований.
