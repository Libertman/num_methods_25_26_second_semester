# Курсовая работа

Вариант состоит из номера темы и номера исследования

Темы:
1. Сравнение решения задач интерполирования изученными методами
2. Сравнение решения интегралов изученными методами
3. Сравнение решения ОДУ 1 порядка изученными методами
4. Сравнение решения ОДУ 2 порядка изученными методами

## Для темы 1
Построить графики и сравнить по ним работу двух методов - из работы 1 и 2:

1. Зависимость бесконечной нормы фактической ошибки от числа узлов сетки - один график для двух методов
2. Графики ошибок на отрезке для двух методов для малого числа узлов.
3. Зависимость координаты максимума модуля фактической ошибки от числа узлов сетки - один график для двух методов

## Для темы 2
Построить графики и сравнить по ним работу двух методов - из работы 3 и 4:

1. Зависимость количества вызовов подынтегральной функции от заданной точности, счетчик должен быть встроен в код функции, один график для двух методов
2. Зависимость фактической погрешности от количества вызовов подынтегральной функции, счетчик должен быть встроен в код функции, один график для двух методов

## Для темы 3
Построить графики и сравнить по ним работу двух методов - из работы 5 и 6:

1. Зависимость бесконечной нормы фактической ошибки и координаты максимума модуля фактической ошибки на отрезке от величины шага
2. Зависимость бесконечной нормы фактической ошибки и координаты максимума модуля фактической ошибки на отрезке от заданной точности
3. Зависимость количества вызовов правой части от величины шага, счетчик должен быть встроен в код функции, один график для двух методов
4. Зависимость бесконечной нормы фактической ошибки от возмущения начальных условий при фиксированном шаге
5. Зависимость фактической погрешности от количества вызовов правой части, счетчик должен быть встроен в код функции, один график для двух методов

## Для темы 4
Поставить задачу Коши для данного уравнения 2 порядка, используя точное решение. Если в 7 работе по варианту рассматривался метод конечных разностей, то провести его сравнение с методом из 5 работы. Если в 7 работе использовали метод из 5 работы, то провести сравнение с методом из 6 работы. Построить графики и сравнить по ним работу двух методов:

1. Зависимость бесконечной нормы фактической ошибки и координаты максимального значения погрешности на отрезке от величины шага
2. Зависимость бесконечной нормы фактической ошибки и координаты максимального значения погрешности на отрезке от заданной точности
3. Зависимость количества вызовов правой части от величины шага, счетчик должен быть встроен в код функции, один график для двух методов
4. Зависимость бесконечной нормы фактической ошибки от возмущения начальных условий при фиксированном шаге
5. Зависимость фактической погрешности от количества вызовов правой части, счетчик должен быть встроен в код функции, один график для двух методов
