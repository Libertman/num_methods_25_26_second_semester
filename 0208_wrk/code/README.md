## 1. Введение и постановка задачи

В курсовой работе проводится сравнительный анализ эффективности двух ключевых классов численного интегрирования, изученных в курсе «Численные методы»:
1. **Метод Ньютона–Котеса** (из лабораторной работы №3): Обобщенный метод трапеций с адаптивным шагом и контролем погрешности по правилу Рунге.
2. **Метод типа Гаусса** (из лабораторной работы №4): Квадратурные формулы Гаусса–Лобатто с фиксированными концами отрезка ($n = 4$ и $n = 5$ узлов) с адаптивным дроблением шага.

### Исследуемый интеграл
$$I = \int_{-10}^{10} f(x)\,dx, \qquad f(x) = (x^5 - 6.2x^3 + 3.5x^2 - 7x)\cos(2x)$$

### Точное аналитическое решение
Ввиду симметрии отрезка интегрирования $[-10, 10]$ интеграл от нечетной части равен нулю. Интегрируя четную компоненту $3.5 x^2 \cos(2x)$ дважды по частям:
$$I_{exact} = 348.25 \sin(20) + 35 \cos(20) \approx \mathbf{332.2160557293755}$$

## 2. Теоретическое сопоставление методов

| Характеристика | Метод трапеций (Ньютон–Котес) | Метод Гаусса–Лобатто ($n=4, 5$) |
|:---|:---:|:---:|
| **Тип сетки** | Равномерная на каждом шаге | Оптимальные корни полиномов Лобатто |
| **Свободные параметры** | Только веса (узлы фиксированы) | Внутренние узлы $x_i$ и веса $w_i$ |
| **Алгебраический порядок точности** | **$1$** (точен для линейных) | **$2n - 3$** ($5$ для $n=4$, **$7$** для $n=5$) |
| **Порядок сходимости по $h$** | $O(h^2)$ | $O(h^6) \dots O(h^8)$ |
| **Критерий адаптивной остановки** | Правило Рунге $\frac{\|I_{half} - I_{whole}\|}{3} \le \varepsilon$ | Разность двух формул $\|I_5 - I_4\| \le \varepsilon$ |
| **Переиспользование узлов** | Границы и середина переиспользуются | Граничные узлы $a$ и $b$ переиспользуются |
| **Затраты на достижение $\varepsilon = 10^{-8}$** | Десятки тысяч вызовов функции | Несколько сотен вызовов функции |

## 3. Математическое описание квадратурных формул

### 3.1. Метод трапеций с правилом Рунге
На элементарном отрезке $[a, b]$ с шагом $H = b - a$:
$$I_{whole} = \frac{H}{2} (f(a) + f(b))$$
При делении отрезка пополам точкой $m = \frac{a+b}{2}$ с шагом $h = H/2$:
$$I_{half} = \frac{h}{2} (f(a) + f(m)) + \frac{h}{2} (f(m) + f(b)) = \frac{H}{4} (f(a) + 2f(m) + f(b))$$
Погрешность метода трапеций имеет порядок $p = 2$. Согласно правилу Рунге:
$$\delta = \frac{|I_{half} - I_{whole}|}{2^2 - 1} = \frac{|I_{half} - I_{whole}|}{3}$$
Если $\delta \le \varepsilon$, принимается значение $I_{half}$. Иначе отрезок делится рекурсивно на $[a, m]$ и $[m, b]$ с допуском $\varepsilon / 2$.

---

### 3.2. Квадратурные формулы Гаусса–Лобатто
На каноническом отрезке $[-1, 1]$:
$$\int_{-1}^1 g(t)\,dt \approx w_1 g(-1) + w_n g(1) + \sum_{i=2}^{n-1} w_i g(t_i)$$
Переход на произвольный подотрезок $[a, b]$:
$$x(t) = \frac{b+a}{2} + \frac{b-a}{2} t, \qquad dx = \frac{b-a}{2} dt$$

#### Формула для $n = 4$ узлов:
* Узлы: $t \in \left\{ -1, \, -\sqrt{1/5}, \, \sqrt{1/5}, \, 1 \right\}$
* Веса: $w_1 = w_4 = \frac{1}{6}, \quad w_2 = w_3 = \frac{5}{6}$
* Алгебраическая точность: $2(4) - 3 = 5$.

#### Формула для $n = 5$ узлов:
* Узлы: $t \in \left\{ -1, \, -\sqrt{3/7}, \, 0, \, \sqrt{3/7}, \, 1 \right\}$
* Веса: $w_1 = w_5 = \frac{1}{10}, \quad w_2 = w_4 = \frac{49}{90}, \quad w_3 = \frac{32}{45}$
* Алгебраическая точность: $2(5) - 3 = 7$.

#### Критерий адаптивного шага:
$$\delta = |I_5 - I_4| \le \varepsilon$$
Если условие выполнено, принимается значение $I_5$. Иначе отрезок делится пополам.

## 5. Вопросы и ответы для защиты курсовой работы

### В1: Почему для темы 2 курсовой работы были выбраны именно метод трапеций и метод Гаусса–Лобатто?
**О:** Данные методы представляют два фундаментальных и диаметрально противоположных подхода к численному интегрированию, детально изученных в семестре:
1. Метод трапеций — простейшая замкнутая квадратурная формула Ньютона–Котеса 2-го порядка с фиксированными эквидистантными узлами.
2. Метод Гаусса–Лобатто — квадратурная формула наивысшей возможной алгебраической точности ($2n-3$) при фиксации только двух граничных точек отрезка. Сравнение наглядно демонстрирует превосходство оптимального выбора узлов над эквидистантным.

### В2: Зачем фиксировать концы отрезка в методе Лобатто, если в обычном методе Гаусса (Лежандра) алгебраический порядок выше ($2n-1$ против $2n-3$)?
**О:** В адаптивных алгоритмах отрезок многократно делится пополам. Правая граница левого подынтервала совпадает с левой границей правого подынтервала ($x = m$). В методе Лобатто граничные узлы входят в квадратуру, поэтому значение $f(m)$ вычисляется **ровно один раз** и переиспользуется обоими смежными подинтервалами. В чистом методе Гаусса концы не являются узлами, и переиспользование значений при бисекции невозможно, что нивелирует выигрыш в порядке точности при адаптивном измельчении.

### В3: Как ведет себя фактическая погрешность в зависимости от числа вызовов подынтегральной функции?
**О:** В логарифмических координатах $(\ln N_{calls}, \ln \varepsilon)$ метод Гаусса–Лобатто имеет значительно более крутой наклон прямой, чем метод трапеций. Это означает, что для достижения одного и того же уменьшения погрешности методу Лобатто требуется на порядок-два меньше дополнительных вычислений подынтегральной функции.
