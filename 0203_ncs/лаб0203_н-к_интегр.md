# Решение интегралов с помощью квадратурных формул Ньютона-Котеса

Индивидуальное задание складывается из:
1. варианта (Ваш вариант) функции [из файла](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/%D1%84%D1%83%D0%BD%D0%BA%D1%86%D0%B8%D0%B8.pdf),
2. варианта метода,
3. варианта эксперимента на 8-10 баллов.

Варианты методов:

1. левых прямоугольников;
2. правых прямоугольников;
3. средних прямоугольников;
4. трапеций;
5. Симпсона;
6. трех восьмых;

### Исследования на 7 баллов:

1. Ручной расчет провести для 1, 2 и 4х разбиений отрезка, оценить точность вычисления интеграла.

2. Написать программу для вычисления приближенного значения интеграла с заданной точностью с помощью обобщенной формулы, для достижения заданной точности использовать правило Рунге. При дроблении шага для достижения точности запрещается повторно вычислять функцию в точках, оставшихся в сетке с прошлой итерации.

3. График зависимости фактической ошибки от заданной точности, отметить линию биссектрисы. Проверить заданную точность: $10^1$, $10^2$, ..., $10^16$

4. График зависимости числа итераций от заданной точности.

5. График фактической ошибки от длины отрезка разбиения, использовать логарифмический масштаб по основанию 2. По графику определить порядок точности применяемой формулы и вычислить константу.

### Исследования (одно, по варианту) на 8-10 баллов:

6. Для заданной функции найти выражение для теоретической ошибки и добавить линии максимальной и минимальной теоретической ошибки на графики ошибок.
7. Модифицировать функцию, добавивь модуль или sign, для получения разрыва первой производной вблизи середины отрезка, выполнить п.3 и 4.
8. Внести погрешность 1%, 2%, 3% в вычисление второго коэффициента полинома. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.
9. Запрограммировать адаптивный метод интегрирования и построить график зависимости длины шага по отрезку и минимальной длины шага от заданной точности.
