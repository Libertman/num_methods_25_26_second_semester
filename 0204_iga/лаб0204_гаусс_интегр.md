# Решение интегралов с помощью квадратурных формул типа Гаусса

Индивидуальное задание складывается из:
1. варианта функции [из файла](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/%D1%84%D1%83%D0%BD%D0%BA%D1%86%D0%B8%D0%B8.pdf),
2. варианта метода,
3. варианта эксперимента на 8-10 баллов.

Варианты методов:
1. Гаусса (без фиксированных узлов) для 2, 3, 4 слагаемых
2. Радо (с одним фиксированным узлом на левом конце) для 2, 3 слагаемых
3. Радо (с одним фиксированным узлом на правом конце) для 2, 3 слагаемых
4. Лобатто (с двумя фиксированными узлами) для 4, 5 слагаемых
5. Ралстона (с двумя фиксированными узлами и двумя коэффициентами разного знака) для 3, 4 слагаемых
6. Чебышева (с равными коэффициентами) для 2, 3, 4, 5 слагаемых

Вместо правила Рунге для формул Гаусса используем простейший подход, сравнивая значения интегралов для формул для $n$ и $n+1$. Для достижения точности используем адаптивное разбиение исходного отрезка на части.

Исследования на 7 баллов:

1. Функция $f(x)$ для определнного интеграла составляется из заданной по варианту $P(x)$, $f(x)=Р(х)\times cos(2x)$.
2. Вычислить точное значение интеграла от функции на отрезке в ручную на бумаге.
3. Построить квадратурные формулы, решив нелинейную систему для узлов и коэффициентов без использования ортогональных полиномов, при решении системы использовать симметрию (на бумаге, прикрепить скан).
4. Ручной расчет провести для 2 вариантов формул, оценить точность вычисления интеграла (на бумаге, прикрепить скан).
5. Написать программу для вычисления приближенного значения интеграла с заданной точностью.
6. График зависимости фактической ошибки от заданной точности, отметить линию биссектрисы.
7. Уточнить значение интеграла с помощью поправки Ричардсона. Построить линию фактической ошибки для уточненного значения интеграла.
8. График фактической ошибки от длины отрезка разбиения, использовать логарифмический масштаб по основанию 2. По графику определить порядок точности применяемой формулы и вычислить константу.

Исследования (одно, по варианту) на 8 баллов:

9. График зависимости числа итераций от заданной точности.
10. Для заданной функции найти выражение для теоретической ошибки и добавить линии максимальной и минимальной теоретической ошибки на графики ошибок.

Исследования (одно, по варианту) на 9 баллов:

11. Внести погрешность 1%, 2%, 3% в вычисление второго коэффициента полинома. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз для заданной точности $1e-5$, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.
12. Модифицировать функцию, добавивь модуль или sign, для получения разрыва первой производной вблизи середины отрезка, выполнить п.6 и 8.

Исследования (одно, по варианту) 10 баллов:

13. Провести сравнение полученных результатов в третьей и четвертой работах по количеству итераций для достижения заданной точности.
14. Провести сравнение полученных результатов в третьей и четвертой работах по устойчивости к возмущениям.
