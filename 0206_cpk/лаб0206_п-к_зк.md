# Решение задачи Коши для ОДУ 1 порядка методами Адамса

Индивидуальное задание складывается из:
1. варианта функции (Ваш вариант) [из файла](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/%D0%9E%D0%94%D0%A3.pdf),
2. варианта метода,
3. варианта эксперимента на 8-10 баллов.

Варианты методов:

1. Метод (экстраполяционный) Адамса-Башфорта 3 порядка
2. Метод (экстраполяционный) Адамса-Башфорта 4 порядка
3. Метод (интерполяционный) Адамса-Моултона 3 порядка
4. Метод (интерполяционный) Адамса-Моултона 4 порядка
5. Метод Эйлера с пересчетом (трапеций)
6. Предиктор-корректор Адамса 2 порядка
7. Предиктор-корректор Адамса 3 порядка
8. Предиктор-корректор Адамса 4 порядка
9. Метод Милна

Разгонные точки получать по методу из 5 работы, если он согласован по точности, иначе использовать метод Рунге-Кутты 4 порядка.

Решение следует получать с заданной точнотью. Точность оценивается:

- для методов с пересчетом: по модулю разности значений на двух последовательных итерациях (как в методе простой итерации), если точность не достигнута, то делается следующая итерация-пересчет;
- для методов предиктор-корректор: по модулю разности значений предиктора и корректора, затем как в методах с пересчетом;
- для экстраполяционных методов: по модулю разности решений на всем отрезке, полученных с полным и половинным шагом, т.е. по правилу Рунге с учетом порядка метода, если точность не достигнута, то требуется уменьшить шаг в два раза.

### Исследования на 7 баллов:

1. Сделать в ручную на бумаге минимальное число шагов метода, чтобы можно было оценить точность полученного решения.
2. Иллюстрация работы метода. Построить графики точного и численных решений для двух фиксированных значений шага на отрезке. Построить график ошибки на отрезке для этих решений.
3. Исследование точности метода. Построить график зависимости фактической погрешности от заданной точности.

### Исследования (одно, по варианту) на 8 баллов:

4. Исследование сходимости метода. Построить зависимость фактической ошибки от фиксированного шага интегрирования, использовать логарифмическую шкалу по основанию 2. Оценить порядок метода. График дополнить линией $h^p$, где $p$ – порядок метода, вычислить константу.
5. Внести погрешность 1%, 2%, 3%, 4%, 5% в начальное условие. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 разпри заданной точности $1e-6$, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.

### Исследования (одно, по варианту) на 9 баллов:

6. Реализовать определение шага интегрирования с помощью достижения заданной точности в методе получения разгонных точек. Далее шаг не меняется. Построить график зависимости фактической погрешности от заданной точности.
7. Задавать разгонные точки по точному решению с погрешностью 1%, 2%, 3%, 4%, 5%, шаг должен давать погрешность не хуже 1e-3 по пункту 3. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.

### Исследование (одно, по варианту) 10 баллов:

8. Провести сравнение результатов 5 и 6 работ. По значению фактической погрешности при одних и тех же значениях заданной точности.
9. Провести сравнение результатов 5 и 6 работ. По возмущению решения при возмущении начального условия на 5%.
