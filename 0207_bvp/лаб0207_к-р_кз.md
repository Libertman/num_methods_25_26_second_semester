# Решение краевой задачи для ОДУ 2-ого порядка

Индивидуальное задание складывается из:
1. варианта функции [из файла](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/%D0%9E%D0%94%D0%A32.pdf),
2. варианта метода,
3. варианта ГУ,
4. варианта эксперимента на 8-10 баллов.

Варианты методов:
1. Метод суперпозиции (сведение к трем задачам Коши)
2. Модифицированный метод суперпозиции (сведение к двум задачам Коши)
3. Метод факторизации (расщепления)
4. Метод пристрелки
5. Метод конечных разностей 1 порядка
6. Метод конечных разностей 2 порядка

Для методов 1-4 в отчете надо привести ту задачу Коши, которая получается для Вашего уравнения и условий. Для численного решения требуется использовать метод из предыдыущих работ в варианте для системы ОДУ, при этом заданная точность достигается по правилу для метода на каждом шаге.
Для методов 5-6 порядок аппроксимации ГУ должен соответствовать заданию. Точность вычисления должна достигаться за счет сравнения результатов на сетках с целым шагом и полушагом. Для решения СЛАУ используется метод прогноки, матрица системы должна сводиться к трехдиагональной.

### Исследования на 7 баллов:

1. Сделать в ручную на бумаге минимальное число шагов метода, чтобы можно было оценить точность полученного решения
2. Иллюстрация работы метода. Построить графики точного и численных решений для двух фиксированных значений шага на отрезке. Построить график ошибки на отрезке для этих решений.
3. Исследование точности метода. Построить график зависимости фактической погрешности от заданной точности.
4. Для методов 1-4 построить график изменения шага по отрезку при заданной точности $1e-6$. Для методов 5-6 построить график зависимости числа итераций от заданной точности.

### Исследования (одно, по варианту) на 8 баллов:

4. Исследование сходимости метода. Построить зависимость фактической ошибки от фиксированного шага интегрирования, использовать логарифмическую шкалу по основанию 2. Оценить порядок метода. График дополнить линией $h^p$, где $p$ – порядок метода, вычислить константу.
5. Внести погрешность 1%, 2%, 3%, 4%, 5% в каждое граничное условие. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз при заданной точности $1e-6$, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.

### Исследования (одно, по варианту) на 9-10 баллов:

6. Внести погрешность 1%, 2%, 3%, 4%, 5% в коэффициент уравнения при первой производной. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз при заданной точности $1e-6$, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.
7.  Внести погрешность 1%, 2%, 3%, 4%, 5% в правую часть уравнения. Требуется вычислить относительную ошибку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз при заданной точности $1e-6$, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.

### Краевая задача:

$$
p(x)y′′+q(x)y′+r(x)y = f(x), 
$$

$$
x ∈ [a, b]
$$

$$
α_0 y(a) + α_1 y′(a) = A
$$

$$
β_0 y(b) + β_1 y′(b) = B
$$

Варианты ГУ:

1. $α_0 ≠ 0$, $α_1 ≠ 0$, $β_1 = 0$
2. $α_1 = 0$, $β_0 ≠ 0$, $β_1 ≠ 0$
3. $α_1 = 0$, $β_1 = 0$

Коэффициенты левой части граничных условий выбирать самостоятельно, правая часть вычисляется по точному решению.
