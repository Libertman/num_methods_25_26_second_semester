# Ручной расчет краевой задачи методом факторизации (метод Рунге-Кутты)

Данный документ содержит расчет минимального числа шагов краевой задачи методом факторизации с использованием **метода Рунге-Кутты** (в соответствии с численным алгоритмом программы) для оценки погрешности решения по правилу Рунге. Выкладки предназначены для переноса от руки в тетрадь (**Исследование №1**).

---

## 1. Постановка задачи и расчетные соотношения

### 1.1. Исходная краевая задача
Уравнение:
$$y'' + (1 + \sin^2 x) y' + (\cos^2 x) y = 3e^x, \quad x \in [0, 1]$$
Точное решение:
$$y_{exact}(x) = e^x$$

Функции коэффициентов:
- $p(x) = 1$
- $q(x) = 1 + \sin^2 x$
- $r(x) = \cos^2 x$
- $f(x) = 3e^x$

Краевые условия:
- При $x = 0$: $y(0) + y'(0) = 2$ ($\alpha_0 = 1, \alpha_1 = 1, A = 2$)
- При $x = 1$: $y(1) = e \approx 2.71828$ ($\beta_0 = 1, \beta_1 = 0, B = e$)

---

### 1.2. Метод факторизации (дифференциальная прогонка)
Связь между решением и производной:
$$y'(x) = \alpha(x) y(x) + \beta(x)$$

**Прямой ход:**
$$\begin{cases}
\alpha'(x) = -\alpha^2(x) - q(x)\alpha(x) - r(x), & \alpha(0) = -1 \\
\beta'(x) = -(\alpha(x) + q(x))\beta(x) + f(x), & \beta(0) = 2
\end{cases}$$

**Обратный ход:**
$$\begin{cases}
y'(x) = \alpha(x) y(x) + \beta(x) \\
y(1) = e \approx 2.71828
\end{cases}$$

---

## 2. Формулы метода Рунге-Кутты 4-го порядка

Для системы $Y' = F(x, Y)$, где $Y = \begin{pmatrix} \alpha \\ \beta \end{pmatrix}$:
$$K_1 = F(x_n, Y_n)$$
$$K_2 = F\left(x_n + \frac{h}{2},\ Y_n + \frac{h}{2} K_1\right)$$
$$K_3 = F\left(x_n + \frac{h}{2},\ Y_n + \frac{h}{2} K_2\right)$$
$$K_4 = F(x_n + h,\ Y_n + h K_3)$$
$$Y_{n+1} = Y_n + \frac{h}{6} (K_1 + 2K_2 + 2K_3 + K_4)$$

Для уравнения обратного хода $y' = \alpha(x) y + \beta(x)$ при шаге назад на интервале $[x_n, x_{n+1}]$ длины $h$ (шагаем от $x_{n+1}$ к $x_n$):
$$k_1 = \alpha_{end} y_{curr} + \beta_{end}$$
$$k_2 = \alpha_{mid} \left(y_{curr} - \frac{h}{2} k_1\right) + \beta_{mid}$$
$$k_3 = \alpha_{mid} \left(y_{curr} - \frac{h}{2} k_2\right) + \beta_{mid}$$
$$k_4 = \alpha_{start} (y_{curr} - h k_3) + \beta_{start}$$
$$y_{prev} = y_{curr} - \frac{h}{6} (k_1 + 2k_2 + 2k_3 + k_4)$$

---

## 3. Расчет с 1 полным шагом $h = 1.0$ ($x_0 = 0.0 \to x_1 = 1.0$)

### 3.1. Прямой ход
Начальная точка $x_0 = 0$: $\alpha(0) = -1.00000$, $\beta(0) = 2.00000$.
Значения функций при $x = 0$: $q(0) = 1.0, r(0) = 1.0, f(0) = 3.0$.

1. **Коэффициент $K_1$ ($x = 0$):**
   $$K_{1,\alpha} = -(-1)^2 - 1(-1) - 1 = -1.00000$$
   $$K_{1,\beta} = -(-1 + 1) \cdot 2 + 3 = 3.00000$$

2. **Коэффициент $K_2$ ($x = 0.5$):**
   Аргументы: $x = 0.5$,
   $\alpha = -1 + 0.5(-1) = -1.50000$,
   $\beta = 2 + 0.5(3) = 3.50000$.
   При $x = 0.5$: $q(0.5) = 1.22985, r(0.5) = 0.77015, f(0.5) = 4.94616$.
   $$K_{2,\alpha} = -(-1.5)^2 - 1.22985(-1.5) - 0.77015 = -1.17538$$
   $$K_{2,\beta} = -(-1.5 + 1.22985) \cdot 3.5 + 4.94616 = 5.89169$$

3. **Коэффициент $K_3$ ($x = 0.5$):**
   Аргументы: $x = 0.5$,
   $\alpha = -1 + 0.5(-1.17538) = -1.58769$,
   $\beta = 2 + 0.5(5.89169) = 4.94585$.
   $$K_{3,\alpha} = -(-1.58769)^2 - 1.22985(-1.58769) - 0.77015 = -1.33829$$
   $$K_{3,\beta} = -(-1.58769 + 1.22985) \cdot 4.94585 + 4.94616 = 6.71599$$

4. **Коэффициент $K_4$ ($x = 1.0$):**
   Аргументы: $x = 1.0$,
   $\alpha = -1 + 1.0(-1.33829) = -2.33829$,
   $\beta = 2 + 1.0(6.71599) = 8.71599$.
   При $x = 1.0$: $q(1.0) = 1.70807, r(1.0) = 0.29193, f(1.0) = 8.15485$.
   $$K_{4,\alpha} = -(-2.33829)^2 - 1.70807(-2.33829) - 0.29193 = -1.76556$$
   $$K_{4,\beta} = -(-2.33829 + 1.70807) \cdot 8.71599 + 8.15485 = 13.64780$$

**Итоговые значения в $x = 1.0$:**
$$\alpha(1.0) = -1.0 + \frac{1.0}{6} [-1.0 + 2(-1.17538) + 2(-1.33829) - 1.76556] = -2.29882$$
$$\beta(1.0) = 2.0 + \frac{1.0}{6} [3.0 + 2(5.89169) + 2(6.71599) + 13.64780] = 8.97719$$

*(Для промежуточного полушага в середине $x = 0.5$: $\alpha_{mid} \approx -1.60254, \beta_{mid} \approx 4.29183$)*.

---

### 3.2. Обратный ход ($x = 1.0 \to 0.0$)
Начальное условие: $y(1) = e \approx 2.71828$. Шаг $h = 1.0$.

1. $k_1 = \alpha(1.0) \cdot y(1) + \beta(1.0) = (-2.29882) \cdot 2.71828 + 8.97719 = 2.72825$
2. $y_{k2} = 2.71828 - 0.5(1.0)(2.72825) = 1.35416$
   $k_2 = \alpha(0.5) \cdot y_{k2} + \beta(0.5) = (-1.60254) \cdot 1.35416 + 4.29183 = 2.12185$
3. $y_{k3} = 2.71828 - 0.5(1.0)(2.12185) = 1.65736$
   $k_3 = \alpha(0.5) \cdot y_{k3} + \beta(0.5) = (-1.60254) \cdot 1.65736 + 4.29183 = 1.63588$
4. $y_{k4} = 2.71828 - 1.0(1.63588) = 1.08240$
   $k_4 = \alpha(0.0) \cdot y_{k4} + \beta(0.0) = (-1.00000) \cdot 1.08240 + 2.00000 = 0.91760$

**Значение решения в $x = 0$:**
$$y_h(0) = 2.71828 - \frac{1.0}{6} [2.72825 + 2(2.12185) + 2(1.63588) + 0.91760] = 0.85806$$

Погрешность решения с шагом $h = 1.0$:
$$\varepsilon_h = |y_h(0) - y_{exact}(0)| = |0.85806 - 1.00000| = 0.14194$$

## 4. Расчет с 2 полушагами $h = 0.5$

Узлы: $x_0 = 0.0$, $x_1 = 0.5$, $x_2 = 1.0$.

### 4.1. Прямой ход
* **Шаг 1 ($0.0 \to 0.5$):**
  Аналогично вычисляются $K_1, K_2, K_3, K_4$ с шагом $h = 0.5$:
  $$\alpha(0.5) = -1.60254, \quad \beta(0.5) = 4.29183$$
  *(в четверти $x = 0.25$: $\alpha \approx -1.27852, \beta \approx 2.92571$)*
* **Шаг 2 ($0.5 \to 1.0$):**
  С начальными данными из точки $x = 0.5$ делаем второй шаг $h = 0.5$:
  $$\alpha(1.0) = -2.37059, \quad \beta(1.0) = 9.16433$$
  *(в трех четвертях $x = 0.75$: $\alpha \approx -1.96077, \beta \approx 6.26907$)*

### 4.2. Обратный ход
Начальное условие: $y(1) = e \approx 2.71828$.
* **Шаг 1 назад ($1.0 \to 0.5$, $h = 0.5$):**
  Используя коэффициенты в $x = 1.0, 0.75, 0.5$:
  $$y_{h/2}(0.5) = 1.63887 \quad (\text{точное } e^{0.5} \approx 1.64872,\ \varepsilon = 0.00985)$$
* **Шаг 2 назад ($0.5 \to 0.0$, $h = 0.5$):**
  Используя коэффициенты в $x = 0.5, 0.25, 0.0$:
  $$y_{h/2}(0) = 0.97913 \quad (\text{точное } 1.00000,\ \varepsilon = 0.02087)$$

Погрешность решения с половинным шагом $h = 0.5$:
$$\varepsilon_{h/2} = |0.97913 - 1.00000| = 0.02087$$

---

## 5. Оценка погрешности по правилу Рунге (для метода 4-го порядка)

Для метода Рунге-Кутты 4-го порядка ($p = 4$):
$$R = \frac{|y_{h/2}(0) - y_h(0)|}{2^4 - 1} = \frac{|0.97913 - 0.85806|}{15} = \frac{0.12107}{15} \approx 0.00807 \quad (8.07 \times 10^{-3})$$
