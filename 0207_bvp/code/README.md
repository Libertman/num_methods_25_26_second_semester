# Полное руководство и разбор лабораторной работы №7
## «Решение краевой задачи для ОДУ 2-го порядка методом факторизации (дифференциальной прогонки)»

---

## 1. В чём заключается проблема? (Краевая задача vs Задача Коши)

В предыдущих лабораторных работах (№5 и №6) решалась **задача Коши**:
* Все начальные условия заданы в **одной точке** (обычно в начале отрезка $x = a$): 
  $$y(a) = y_0, \quad y'(a) = y'_0$$
* В этом случае решение находится простым последовательным «шаганием» вперед от $x_n$ к $x_{n+1}$ (методами Эйлера, Адамса или Рунге-Кутты).

В данной лабораторной работе решается **краевая задача (Boundary Value Problem — BVP)**:
* Условия заданы **на разных концах** отрезка $[a, b]$:
  - Одно условие на левом конце $x = a$: $\alpha_0 y(a) + \alpha_1 y'(a) = A$
  - Второе условие на правом конце $x = b$: $\beta_0 y(b) + \beta_1 y'(b) = B$

### В чём фундаментальная сложность?
Мы **не можем** сразу запустить метод Рунге-Кутты из точки $x = a$, потому что нам неизвестно полное состояние системы в точке $a$ — известно лишь линейное соотношение между $y(a)$ и $y'(a)$, но ни $y(a)$, ни $y'(a)$ по отдельности мы не знаем!

---

## 2. Идея и математический вывод метода факторизации (расщепления)

Метод факторизации (в отечественной литературе известный как **метод дифференциальной прогонки**) позволяет обойти эту трудность путем переноса граничного условия с одного конца на другой.

### 2.1. Исходная задача
Дано линейное ОДУ второго порядка:
$$p(x) y'' + q(x) y' + r(x) y = f(x), \quad x \in [a, b]$$
В нашем варианте (вариант 4, отрезок $[0, 1]$):
* $p(x) = 1$
* $q(x) = 1 + \sin^2(x)$
* $r(x) = \cos^2(x)$
* $f(x) = 3e^x$
* Точное решение: $y_{exact}(x) = e^x$

Краевые условия (вариант ГУ 1: $\alpha_0 \ne 0, \alpha_1 \ne 0, \beta_1 = 0$):
* В $x = 0$: $1 \cdot y(0) + 1 \cdot y'(0) = 2$ ($\alpha_0 = 1, \alpha_1 = 1, A = 2$)
* В $x = 1$: $1 \cdot y(1) + 0 \cdot y'(1) = e$ ($\beta_0 = 1, \beta_1 = 0, B = e$)

---

### 2.2. Прогоночное соотношение (факторизация)
Мы предполагаем, что в любой точке $x \in [a, b]$ между решением $y(x)$ и его производной $y'(x)$ существует линейная связь:
$$y'(x) = \alpha(x) y(x) + \beta(x)$$
где $\alpha(x)$ и $\beta(x)$ — неизвестные функции (прогоночные коэффициенты), которые нам предстоит найти.

#### Вывод дифференциальных уравнений для $\alpha(x)$ и $\beta(x)$:
1. Продифференцируем прогоночное соотношение по $x$:
   $$y''(x) = \alpha'(x) y(x) + \alpha(x) y'(x) + \beta'(x)$$
2. Подставим вместо $y'(x)$ само прогоночное соотношение $y' = \alpha y + \beta$:
   $$y''(x) = \alpha'(x) y(x) + \alpha(x) [\alpha(x) y(x) + \beta(x)] + \beta'(x) = [\alpha'(x) + \alpha^2(x)] y(x) + \alpha(x) \beta(x) + \beta'(x)$$
3. Теперь выразим $y''(x)$ из исходного дифференциального уравнения ($p(x) = 1$):
   $$y''(x) = -q(x) y'(x) - r(x) y(x) + f(x)$$
   И снова подставим $y' = \alpha y + \beta$:
   $$y''(x) = -q(x) [\alpha(x) y(x) + \beta(x)] - r(x) y(x) + f(x) = -[q(x)\alpha(x) + r(x)] y(x) + [f(x) - q(x)\beta(x)]$$
4. Приравняем два полученных выражения для $y''(x)$:
   $$[\alpha' + \alpha^2] y + \alpha \beta + \beta' = -[q\alpha + r] y + [f - q\beta]$$
   Перенесем всё в одну часть:
   $$\underbrace{[\alpha'(x) + \alpha^2(x) + q(x)\alpha(x) + r(x)]}_{\text{должно быть } 0} \cdot y(x) + \underbrace{[\beta'(x) + (\alpha(x) + q(x))\beta(x) - f(x)]}_{\text{должно быть } 0} = 0$$

Так как это равенство должно выполняться для **любого** решения $y(x)$, коэффициенты обязаны обнуляться независимо. Получаем **систему дифференциальных уравнений прямого хода**:
$$\begin{cases}
\alpha'(x) = -\alpha^2(x) - q(x)\alpha(x) - r(x) & \text{(нелинейное уравнение Риккати)} \\
\beta'(x) = -(\alpha(x) + q(x))\beta(x) + f(x) & \text{(линейное уравнение 1-го порядка)}
\end{cases}$$

---

### 2.3. Начальные условия для прямого хода ($x = 0$)
На левом конце задано:
$$\alpha_0 y(0) + \alpha_1 y'(0) = A \implies y'(0) = -\frac{\alpha_0}{\alpha_1} y(0) + \frac{A}{\alpha_1}$$
Сравнивая это с $y'(0) = \alpha(0) y(0) + \beta(0)$, однозначно получаем:
$$\alpha(0) = -\frac{\alpha_0}{\alpha_1} = -\frac{1}{1} = -1, \qquad \beta(0) = \frac{A}{\alpha_1} = \frac{2}{1} = 2$$

---

### 2.4. Сопряжение на правом конце ($x = 1$)
Интегрируя систему вперед от $x = 0$ до $x = 1$, мы находим числовые значения $\alpha(1)$ и $\beta(1)$.
В точке $x = 1$ действуют:
1. Правое краевое условие: $\beta_0 y(1) + \beta_1 y'(1) = B$
2. Прогоночное соотношение: $y'(1) = \alpha(1) y(1) + \beta(1)$

Подставляем $y'(1)$ в краевое условие:
$$\beta_0 y(1) + \beta_1 [\alpha(1) y(1) + \beta(1)] = B \implies [\beta_0 + \beta_1 \alpha(1)] y(1) + \beta_1 \beta(1) = B$$
Отсюда находим точное значение решения в правой точке:
$$y(1) = \frac{B - \beta_1 \beta(1)}{\beta_0 + \beta_1 \alpha(1)}$$
Для нашего варианта ($\beta_1 = 0, \beta_0 = 1, B = e$):
$$y(1) = \frac{e - 0}{1 + 0} = e \approx 2.71828$$

---

### 2.5. Обратный ход ($x = 1 \to 0$)
Теперь у нас есть значение $y(1) = e$ и уравнение первого порядка:
$$\frac{dy}{dx} = \alpha(x) y(x) + \beta(x)$$
Мы интегрируем его **назад** от $x = 1$ до $x = 0$, используя значения $\alpha(x)$ и $\beta(x)$, найденные на прямом ходе. В результате получаем значения $y(x)$ во всех узлах сетки!

---

## 3. Архитектура C++ реализации (`main.cpp`)

Код разбит на независимые логические блоки (каждая функция решает строго одну задачу):

```
main.cpp
├── 1. Модель задачи (уравнения и точное решение)
│    ├── q_func(x), r_func(x), f_func(x)
│    └── exact_solution(x)
│
├── 2. Ядро численного метода (Рунге-Кутта 4-го порядка)
│    ├── forward_rhs(...)        — вычисление правых частей системы (d_alpha, d_beta)
│    ├── rk4_forward_step(...)   — один шаг RK4 вперед для пары (alpha, beta)
│    └── rk4_backward_step(...)  — один шаг RK4 назад для y' = alpha*y + beta
│
├── 3. Методы факторизации
│    ├── solve_factorization_fixed(...)    — решение с постоянным шагом h
│    └── solve_factorization_adaptive(...) — решение с адаптивным шагом по правилу Рунге
│
├── 4. Исследования (Research)
│    ├── compute_errors(...), compute_max_error(...)
│    └── accuracy_study(...)               — серия запусков при eps от 1e-2 до 1e-8
│
└── 5. Модуль вывода данных (CSV)
     ├── write_solution_csv(...)
     ├── write_error_csv(...)
     ├── write_accuracy_csv(...)
     └── write_step_size_csv(...)
```

### Ключевые моменты реализации:

1. **Сохранение промежуточных данных для RK4 обратного хода (`SweepInterval`):**
   Чтобы на обратном ходе применить высокоточный метод Рунге-Кутты 4-го порядка к уравнению $y' = \alpha y + \beta$, нам нужны значения $\alpha$ и $\beta$ не только на краях шага, но и в **середине** интервала ($x + h/2$).
   В структуре `SweepInterval` сохраняются:
   `alpha_start, beta_start`, `alpha_mid, beta_mid`, `alpha_end, beta_end`.
   Благодаря этому и прямой, и обратный ход имеют **чистый 4-й порядок точности** без потери точности на интерполяции.

2. **Адаптивный шаг по правилу Рунге:**
   На каждом шаге делаются:
   - 1 шаг величины $h \implies (\alpha_{full}, \beta_{full})$
   - 2 шага величины $h/2 \implies (\alpha_{half}, \beta_{half})$
   - Локальная погрешность для метода 4 порядка:
     $$\delta = \frac{\max(|\alpha_{half} - \alpha_{full}|, |\beta_{half} - \beta_{full}|)}{2^4 - 1} = \frac{\Delta}{15}$$
   - Если $\delta \le \varepsilon$: шаг принимается, узел сохраняется, следующий шаг вычисляется как:
     $$h_{next} = h \cdot 0.9 \cdot \left(\frac{\varepsilon}{\delta}\right)^{1/5}$$
   - Если $\delta > \varepsilon$: шаг отвергается, шаг уменьшается и пересчитывается заново.

## 5. Подготовка к защите: вопросы преподавателя и сравнение методов

Преподаватель на защите обязательно будет спрашивать не только про факторизацию, но и про **другие методы решения краевых задач**, представленные в задании:

### Вопрос 1. Какие вообще бывают подходы к решению краевых задач?
Все методы делятся на два больших класса:
1. **Методы редукции к задаче Коши (стрельбовые методы и прогонка):** краевая задача сводится к одной или нескольким задачам Коши, которые решаются стандартными одношаговыми или многошаговыми методами (Рунге-Кутта, Адамс). Сюда входят: метод суперпозиции, факторизация, метод пристрелки.
2. **Сеточные методы (конечно-разностные методы, МКР):** производные аппроксимируются разностными отношениями во всех внутренних узлах сетки одновременно, что приводит к системе линейных алгебраических уравнений (СЛАУ) с трехдиагональной матрицей, решаемой методом прогонки Томаса.

---

### Вопрос 2. В чём разница между методами суперпозиции (методы 1 и 2) и факторизацией (метод 3)?
* **Метод суперпозиции (сведение к 3 задачам Коши):**
  Общее решение линейного неоднородного уравнения представляется как:
  $$y(x) = y_0(x) + C_1 y_1(x) + C_2 y_2(x)$$
  где $y_0$ — частное решение неоднородного ОДУ, а $y_1, y_2$ — фундаментальная система решений однородного ОДУ.
  Решаются 3 независимые задачи Коши из $x = a$, затем из граничных условий составляется система $2 \times 2$ относительно констант $C_1, C_2$.
* **Модифицированный метод суперпозиции (к 2 задачам Коши):**
  Начальные условия для $y_0(x)$ и $y_1(x)$ выбираются так, чтобы они уже удовлетворяли левому граничному условию. Тогда остается найти только одну константу $C$ из правого граничного условия: $y(x) = y_0(x) + C y_1(x)$.
* **Главный недостаток суперпозиции:**
  Если однородное уравнение имеет быстрорастущие (экспоненциальные) решения, фундаментальные решения $y_1(x)$ и $y_2(x)$ стремятся к линейной зависимости при численном счете (эффект потери устойчивости). Система для $C_1, C_2$ становится плохо обусловленной.
* **Преимущество факторизации:**
  Факторизация переносит не сами решения, а **соотношение** между решением и производной. Уравнение Риккати для $\alpha(x)$ часто обладает свойством диссипативности (самостабилизации), что делает дифференциальную прогонку значительно устойчивее к росту погрешностей.

---

### Вопрос 3. Как работает метод пристрелки (метод 4)?
1. В левой точке $x = a$ нам известно только одно условие (например, $y(a) = y_0$). Значение производной $y'(a) = \eta$ нам неизвестно.
2. Мы **угадываем** параметр $\eta$ (угол наклона «пушки») и решаем обычную задачу Коши от $a$ до $b$.
3. В точке $b$ смотрим на невязку краевого условия:
   $$\Phi(\eta) = \beta_0 y(b; \eta) + \beta_1 y'(b; \eta) - B$$
4. Задача сводится к нахождению корня нелинейного (или линейного) уравнения $\Phi(\eta) = 0$. Корень ищется методами деления пополам, секущих или Ньютона. При каждом вычислении функции $\Phi(\eta)$ приходится заново интегрировать задачу Коши на всем отрезке!

---

### Вопрос 4. Как работают методы конечных разностей (методы 5 и 6)?
1. Отрезок $[a, b]$ разбивается сеткой с шагом $h$: $x_i = a + i \cdot h$.
2. Производные во внутренних узлах аппроксимируются конечными разностями:
   $$y'_i \approx \frac{y_{i+1} - y_{i-1}}{2h}, \qquad y''_i \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}$$
3. Подстановка в уравнение дает трехточечные уравнения:
   $$A_i y_{i-1} + B_i y_i + C_i y_{i+1} = F_i, \quad i = 1, \dots, N-1$$
4. Граничные условия аппроксимируются:
   - 1-й порядок: $y'(a) \approx \frac{y_1 - y_0}{h}$
   - 2-й порядок: через фиктивный узел $x_{-1}$ или одностороннюю разность трех точек $\frac{-3y_0 + 4y_1 - y_2}{2h}$.
5. Получается СЛАУ с трехдиагональной матрицей, которая решается алгебраическим методом прогонки за $O(N)$ операций.

---

### Вопрос 5. В каких случаях метод факторизации может дать сбой? (Условия применимости)
* Уравнение для $\alpha(x)$ является **уравнением Риккати** ($\alpha' = -\alpha^2 - q\alpha - r$). Решения нелинейных уравнений могут уходить в бесконечность за конечное время (полюса). Если на отрезке $[a, b]$ функция $\alpha(x) \to -\infty$, то дифференциальная прогонка «развалится».
* В нашей задаче:
  $q(x) = 1 + \sin^2(x) \ge 1 > 0$, $r(x) = \cos^2(x) \ge 0$, $\alpha(0) = -1 < 0$.
  При отрицательных $\alpha$ правая часть ограничена, $\alpha(x)$ плавно меняется от $-1.0$ до $-2.37$, оставаясь строго конечной.
* Также требуется, чтобы $\beta_0 + \beta_1 \alpha(b) \ne 0$. В нашем случае $\beta_1 = 0, \beta_0 = 1 \implies 1 \ne 0$. Условие выполнено строго.
