# Интерполяционные полиномы приближения табличных функций. 
Индивидуальное задание состоит из номера метода и номера доп.исследования, функции надо взять [из файла](https://gitverse.ru/mackoel/nummeth/content/main/semestr_2/%D1%84%D1%83%D0%BD%D0%BA%D1%86%D0%B8%D0%B8%20%D0%B4%D0%BB%D1%8F%20%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D0%BF%D0%BE%D0%BB%D1%8F%D1%86%D0%B8%D0%B8.pdf) по номеру своего варианта.

Варианты методов:

1. Полином в форме Лагранжа
2. Полином в форме Ньютона слева-направо (вперед)
3. Полином в форме Ньютона справа-налево (назад)
4. Полином Эрмита, производные вычисляются с помощью конечных разностей 1 порядка
5. Полином Эрмита, производные вычисляются с помощью конечных разностей 2 порядка

Программа не должна вычислять коэффициенты полинома для канонической формы, а должна вычислять значение интерполянта в заданных точках. Величины, одинаковые для всех точек, должны вычисляться заранее.

Численные исследования проводятся для двух типов сеток -- равномерной сетки и сетки Чебышева.

Для исследований и построения графиков функции вычисляются на проверочной сетке - в большом количестве точек, например 10000, которые не совпадают с узлами сетки для построения полинома или сплайна.

### Исследования на 7 баллов:

1. Выбрать для данных по варианту функций интервал непрерывности.
2. Для малого числа узлов (3..10) вычислить в ручную на бумаге значения полинома по заданию и фактической ошибки (разность между значением функции и полинома) в узлах и серединах между узлами. Получить полином в каноническом виде (по степеням х). Полином требуется привести к каноническому виду.
3. Иллюстрация работы метода интерполяции полиномом. Требуется построить на одном графике функцию, полином для 3 вариантов небольшого числа узлов (5...10), отметить узлы. На другом графике построить функции поточечной ошибки для этих же полиномов. Провести линию теоретической ошибки, построенной для одного из 3х полиномов привести в отчете формулу для расчета теор. ошибки.
4. Зависимость ошибки интерполяции от степени интерполяционного полинома (количества узлов). Требуется построить график максимальной ошибки на отрезке в зависимости от числа узлов: 5...100. Для каждого случая вычисляется ошибка -- норма разности вектора значений функции и полинома на проверочной сетке.

### Дополнительные исследования, одно по варианту, на 8-9 баллов в зависимости от качества работы:

5. Зависимость ошибки в выбранных точках от степени интерполяционного полинома (количества узлов). Две точки требуется выбрать из проверочной сетки, в них вычисляется модуль разности значений функции и полинома для полиномов, построенных по разному количеству узлов (как в п.3). Указать в отчете точные координаты этих выбранных точек.
6. Зависимость ошибки интерполяционного полинома при возмущении данных. В значение функции в точках сетки для построения полинома вносятся возмущения максимальной величины 1%, 2%, 3%, 4%, 5%. Возмущения вносятся в каждую точку случайно. Требуется вычислить относительную ошибку по всему отрезку для каждого значения максимального возмущения и построить график. Эксперимент выполняется 20 раз, строится график типа боксплот, по оси х среднее фактическое возмущение данных в эксперименте.

### Дополнительные исследования, одно по варианту, на 10 баллов:

7. Модифицировать сетку так, чтобы для некоторого числа узлов ошибка стала меньше, чем на исходной сетке. Привести формулу для узлов сетки. Построить на одном графике исходную функцию, полином для выбранного числа узлов на равномерной и модифицированной сетке. Для того же числа узлов на модифицированной сетке ошибка должна быть меньше.
8. На основе данной функции построить функцию, имеющую разрыв первой производной вблизи середины отрезка, точка разрыва производной не должна попадать в узел сетки. Выполнить пп.3-4 для этих условий.
